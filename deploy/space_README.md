# Airline Assistant Prototype

A Strathmore University student project (ICS Project II): a conversational
assistant for airline customer support built with Rasa, BERT, FastAPI and
PostgreSQL. It is a prototype with sample data, not an airline service:
bookings take no payment and issue no ticket.

Open the app at its own address (the `.hf.space` link) rather than inside
this page, so that signing in works.

Source code and documentation: https://github.com/JoshuaBaraka24/airline-chatbot
